# Library-PPT
[어린이서비스] 어린이도서관 견학 PPT — 달성어린이숲도서관 견학 보고 (15장, 5–7분 발표)

## 보기
- 웹 슬라이드: https://lotussyyy.github.io/library-ppt/
- 조작: ← → 키(또는 스와이프)로 이동, **N** 발표 대본 보기, **F** 전체 화면
- 특정 페이지로 바로 가기: 주소 끝에 `#5` 처럼 페이지 번호 붙이기

## 파일 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 슬라이드 보기 페이지 (15장 + 발표 대본) |
| `발표대본.md` | 페이지별 발표 대본 |
| `slides/` | 슬라이드 원본 HTML(01~15)과 순서 정보 `deck.json` |
| `images/` | 견학 때 직접 찍은 사진 8장 |

## 편집
슬라이드 편집은 Claude 덱(원본)에서 하고, 바뀐 내용을 이 저장소에 다시 올리는 방식입니다.
이 저장소의 `index.html`은 보기용 사본입니다.
